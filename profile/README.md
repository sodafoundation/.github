# [SODA Foundation](https://www.sodafoundation.io/)

SODA Foundation is an open source project under the Linux Foundation and the home of
**[Aitra](https://aitra.ai)**, open source AI infrastructure intelligence, from model to facility.

## ⭐ Featured project: Aitra

**[Aitra](https://aitra.ai)** helps teams measure, understand, attribute, connect and optimize how AI
uses infrastructure, from the model down to the GPU, server and data center.

- Website: [aitra.ai](https://aitra.ai)
- Code: [Aitra Meter](https://github.com/sodafoundation/aitra-meter), Kubernetes-native AI inference efficiency measurement

## Other SODA projects

- **[Contexture](https://github.com/sodafoundation/contexture)**, operational context for AI agents
- **[Delfin](https://github.com/sodafoundation/delfin)**, unified infrastructure and storage resource management

## About SODA

SODA Foundation fosters an ecosystem of open source data and AI infrastructure software. It offers a
neutral forum for cross-project collaboration and integration, and provides end users quality
end-to-end solutions from edge to core to cloud.
